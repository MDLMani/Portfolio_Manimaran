# Manimaran — Cinematic Portfolio

Immersive scroll portfolio adapted from the Aura **Aquaria Cinematic** template design and animation system (GSAP ScrollTrigger, Lenis, Three.js).

## Run locally

```bash
cd Portfolio_Manimaran
python3 -m http.server 5173
```

Open http://localhost:5173

## Contents

- `index.html` — full cinematic experience + portfolio copy
- `assets/` — hero gate card images
