# Manimaran — Portfolio

React + Vite portfolio with a horizontal accordion hero, GSAP ambient motion, light/dark theme toggle, and scroll story sections.

## Run

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

## Content

1. About — background, skills, working style
2. Experience — Zcodia Technologies
3. Projects — Delivery, AI Assistant, Work Tracking
4. Q / A Testing — what was tested and what quality practices are known
